# PhotoTend 宣传页动态与表单优化设计

## 目标

在不引入视频或大型动画依赖的前提下，让宣传页更真实地展示 PhotoTend 的手势整理体验，
同时提高外部存储导入场景的完成度，并改善版本通知表单的阅读与操作节奏。

## Hero 交互演示

Hero 右侧保留现有手机轮廓，但内部改为独立的 React 客户端组件。组件展示照片卡片、
日期信息、缩略图轨道、操作提示和回收站反馈。

空闲状态自动循环演示：

1. 左滑当前照片，下一张从右侧进入。
2. 上滑当前照片，顶部出现回收站状态。
3. 下滑触发撤销反馈，并恢复上一张照片。
4. 短暂停留后重新循环。

用户可以使用鼠标、触摸或触控笔拖动照片。组件通过 Pointer Events 统一处理输入，
在移动距离超过阈值时按横向或纵向锁定方向。左右拖动切换照片；向上拖动模拟移入回收站；
向下拖动模拟撤销。交互期间暂停自动播放，完成后延迟恢复。

所有运动只使用 `transform` 与 `opacity`。当系统启用 `prefers-reduced-motion` 时，
关闭自动播放和过渡，只保留完整的静态界面。操作提示通过隐藏状态文字向辅助技术说明，
装饰 SVG 本身不重复播报。

## SD 卡导入场景

使用内联 SVG 绘制 SD 卡，不依赖外部图片。图形包含标准切角、锁定槽、金属触点、
容量标识和细微轮廓层次。虚线传输路径上加入小型照片缩略图，以平移和淡入淡出表现
“存储卡内容进入 PhotoTend”的过程。

缩略图最终汇入现有照片叠层，从而把图标、传输路径和结果连成一个清晰叙事。
减少动态效果时保留 SD 卡、路径与一张静态缩略图。

## 表单布局

表单保持邮箱、平台偏好、明确同意和提交按钮四层结构，但增加层级间距：

- 邮箱标签与输入框形成紧凑组。
- 邮箱组与平台组之间使用更明显的段落间距。
- 平台选项在宽屏保持三列，在窄屏切换为单列。
- 同意项扩大点击区域，文本使用更舒适的行高与最大行宽。
- 按钮和隐私说明与同意项分开，避免信息挤在一起。

不改变提交字段、验证规则和后端数据结构。

## 验证

- 单元测试验证交互组件的可拖动语义、状态提示和 SD SVG 结构。
- 浏览器测试验证自动演示会改变状态、用户拖动可完成动作，以及减少动态效果会停止自动播放。
- 继续执行移动、平板和桌面无横向溢出检查。
- 使用 axe 检查严重和关键级别无障碍问题。
