# PhotoTend 根营销页恢复设计

## 背景

PhotoTend 营销站改为 Next.js 静态导出后，原先由服务端代理完成的根路径语言跳转被移除。完整营销页仍然发布在 `/zh-CN` 和 `/en`，但根路径 `/` 继续渲染早期的简版兜底页，导致主域名只显示标题、说明和 Android 下载链接。

## 方案比较

1. **根路径直接渲染完整中文营销页（采用）**：复用现有中文营销页组件，不依赖运行时跳转或托管平台配置；静态导出后主域名即可完整展示。
2. **根路径客户端跳转到 `/zh-CN`**：实现简单，但首次访问会多一次跳转，并可能出现页面闪烁。
3. **在 Vercel 配置根路径重写或重定向**：浏览器行为清晰，但把站点正确性绑定到部署平台配置，不利于当前可移植的静态发布目标。

## 设计

- 根路径 `/` 复用与 `/zh-CN` 相同的营销页面结构和中文内容。
- 保留 `/zh-CN` 与 `/en` 两个显式语言地址，以及现有语言切换行为。
- 根路径继续使用现有全局中文元数据；不改变下载地址、页面视觉、动画或产品文案。
- 抽取共享营销页面内容，避免根路径和本地化路径各自维护一份组件清单。

## 验证

- 增加根页面测试，确认完整营销模块出现，而不是简版兜底内容。
- 保留并运行本地化页面测试。
- 运行网站单元测试、类型检查、代码检查和静态构建。
- 检查导出的 `out/index.html` 包含完整营销页标记。
